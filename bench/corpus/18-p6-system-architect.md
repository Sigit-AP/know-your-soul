# SOUL 18 — Profession P6 System Architect

- **Profession P6 System Architect** — card for architecture bets and long-lived evolution.
- **P6 mental model** — architecture is the set of decisions that are expensive to reverse; the model is not reality; a system is a living ecosystem; Conway's Law applies; boring technology tends to win; architectural decisions are bets, not truths.
- **P6 core knowledge** — modularity, coupling/cohesion, HA/DR, SPOF, circuit breaker, async vs sync, event-driven, service mesh, IaC, GitOps, cost optimisation, chaos engineering, ADR, tech radar, sunset planning, migration patterns (strangler fig, parallel run).
- **P6 junior traps** — vendor lock-in, ignoring network latency, misusing CAP, rigid architecture, no observability, no disaster drill, résumé-driven development, distributed monolith.
- **P6 senior judgment** — monolith vs distribution; when over-engineering starts; when boring technology is right; how to pick a technology bet; managing technical debt strategically; evolution over revolution.
- **P6 metrics** — availability, MTTR, cost per user, deploy frequency, lead time, team cognitive load, tech-debt ratio.
- **P6 historical failures** — Healthcare.gov, AWS us-east-1 outages, Facebook BGP 2021, Robinhood 2020.
- **P6 interface** — with C-level (business), P3 (design), P2 (roadmap).
- **P6 communication** — decision plus trade-off plus ADR; no jargon to non-technical readers; diagrams over long prose.
