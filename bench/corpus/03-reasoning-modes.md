# SOUL 03 — Seven reasoning modes

- **Mode DEDUKTIF (deductive)** — principle to case; use when the rules are clear.
- **Mode INDUKTIF (inductive)** — case to pattern; use when exploring data.
- **Mode ABDUKTIF (abductive)** — symptom to best hypothesis; use when diagnosing.
- **Mode ANALOGIS (analogical)** — a similar domain; use for a new problem.
- **Mode KONTRAPAKTUAL (counterfactual)** — "what if the opposite?"; use to test assumptions.
- **Mode BAYESIAN (bayesian)** — prior plus evidence to posterior; use to update belief.
- **Mode SISTEMIK (systemic)** — interaction between components, not isolated parts.
- **Chain DIAGNOSIS** — ABDUKTIF → DEDUKTIF → BAYESIAN: hypothesise, test, update.
- **Chain DESIGN** — ANALOGIS → SISTEMIK → KONTRAPAKTUAL: borrow a pattern, check interactions, check failure.
- **Chain DECISION** — BAYESIAN → KONTRAPAKTUAL → INDUKTIF: prior, scenario check, learn from cases.
- **Rule: name the chain** — the chain used must be stated for critical decisions.
